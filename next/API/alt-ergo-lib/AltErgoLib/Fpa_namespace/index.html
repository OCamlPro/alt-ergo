Module AltErgoLib.Fpa_namespace

Loading of the SMT-LIB FPA prelude.

The statements of the prelude src/plugins/smt-float/smt-lib-fpa.ae are renamed before type-checking: the declared and defined symbols are prefixed with ae.fp. (add becomes ae.fp.add), pow2 is the builtin int.pow2 and round is the builtin ae.float.

Only logic declarations, function and predicate definitions, and axioms are supported.

type t

The state of the renaming of the prelude.

val create : unit -> t

Creates a new renaming state, to be used for a single loading of the prelude.

val rewrite : t -> Dolmen.Std.Statement.t -> Dolmen.Std.Statement.t

rewrite t stmt renames the symbols of the parsed statement stmt of the prelude.

  • raises Failure

    if the statement is not supported.
