Module Util.Syntax

val (let&) : (scope:('a -> 'b) -> 'b) -> ('a -> 'b) -> 'b

let& is a "resource binding" operator from memprof-limits

It provides a nice notation for resources cleaned up at the end of scope:

  let f x =
    let& () = Steps.with_step_limit limit in
    ...
